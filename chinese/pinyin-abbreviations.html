Hanyu Pinyin Abbreviations

Notes on the unintuitive rules of Hanyu Pinyin spelling conventions

Home / Chinese / Pinyin Abbreviations

Hanyu Pinyin uses abbreviations that simplify it for experienced readers but can confuse newcomers. Keep in mind: pinyin spellings don't always match pronunciation.

  • In three cases, an abbreviation is made by removing a letter:
    • -iou = -iu
    • -uei = -ui
    • -uen = -un
  • Where no ambiguity arises, a vowel with a diacritic is written without the diacritic, for convenience. The sound [ɛ] (as in English red) was originally written ê, but it is replaced everywhere it occurs.
    • -iê = -ie
    • -iên = -ian
  • If the initial is j, q, or x, replace ü with u.
    • (jqx)-ü = -u
    • (jqx)-üê = -ue
    • (jqx)-üên = -uan
    • (jqx)-ün = -un
  • In most cases, if there is no initial, the spelling changes to keep syllable boundaries clear when syllables are written together. If there is no initial and there is a ü, replace ü with yu.
    • ü = yu
    • üê = yue
    • üên = yuan
  • If there is no initial and the vowel is i (with no diphthong), add a y:
    • i = yi
    • in = yin
    • ing = ying
  • If there is no initial and there is a diphthong beginning with i, replace i with y.
    • iê = ye
    • iên = yan
    • iou = you
    • ia = ya
    • iao = yao
  • If there is no initial and the vowel is u (with no diphthong), add a w:
    • u = wu
  • If there is no initial and there is a diphthong beginning with u, replace u with w.
    • ua = wa
    • uai = wai
    • uei = wei
    • uan = wan
    • uen = wen

Remember also that -i represents a different sound depending on whether the initial is one of {sh, ch, zh, r}, {z, c, s}, or {b, p, m, d, t, n, l, j, q, x}. One letter represents different sounds in other finals too, but those differences are less misleading.
