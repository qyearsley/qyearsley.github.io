Set Up the Puzzle

Give each islander a one-letter name and, if they speak, a statement. Write a statement the way Truth Tables does: other islanders' names (lowercase) stand for "that islander is a knight," combined with and, or, not, xor, nand, implies, and eq. Leave a statement blank for an islander who says nothing.

    How It Works

    Each islander is a boolean variable: true if they're a knight, false if they're a knave. A knight's statement is true; a knave's is false -- so for an islander x with a statement, the puzzle requires x eq (statement). ANDing that constraint together for every islander who speaks gives one combined expression, which the same truth-table code this page reuses can parse and evaluate over every combination of knight/knave.

    A puzzle can come out three ways: exactly one row satisfies the constraint (a unique solution), no row does (the statements contradict each other, however anyone is assigned), or more than one row does (the statements are consistent but don't pin down every islander).
