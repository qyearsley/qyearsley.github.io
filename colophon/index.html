How This Site Is Built

Plain HTML, a small build script, and no framework.

Home / Colophon

The source for this site is on GitHub.

Pages are plain HTML, CSS, and JavaScript, with no framework or bundler. A small build script, build.js, renders the resume, generates the Chinese pages, builds the sitemap, and checks every internal link. Tests run on Jest, and ESLint, Prettier, Stylelint, and HTMLHint handle linting and formatting. The site deploys to GitHub Pages only if all of them pass.

The Chinese pages were translated with machine help, and no native Chinese speaker has checked them yet.

Press ? for keyboard shortcuts. The theme button switches between light, dark, and your system setting.

Why "colophon"?

A colophon is the note at the end of a book that says how it was made: the typeface, the paper, the printer. The word comes from the Greek kolophōn, "summit" or "finishing touch".
