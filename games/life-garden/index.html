How it works

Every generation each cell counts its 8 neighbours, but each species counts a different set of them.

Species Counts Lives Born Age
🌿 Grass grass 2–3 3 never
🌸 In bloom grass 2–3 — never
🐝 Bee bloom, bees 1–3 3 20
🐇 Rabbit grass any 2–3 25
🦊 Fox rabbits any 3 45
  • Grass blooms. Grass that survives 8 generations flowers. It is the same plant under the same rules, just older.
  • Bees pollinate. Grass next to a bee spreads on 2 neighbours instead of 3.
  • Rabbits eat grass. Grass next to 2+ rabbits dies.
  • Foxes eat rabbits. A rabbit next to a fox dies.
  • Eating is resolved first, so nothing survives being eaten.
  • A rabbit counts grass and a fox counts rabbits, so the count is food rather than crowding: they live to their age whatever the count, unless something eats them.
